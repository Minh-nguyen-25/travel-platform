# Ảnh chụp thật của các địa danh

Mở trang `/images/destinations/credits.html` trên web để xem đủ ảnh, tác giả, nguồn và giấy phép.

## Cập nhật database

Chạy từ thư mục backend:

```powershell
npm run photos:preview
npm run photos:import
```

Import thay ảnh seed chung bằng ảnh đúng địa danh, giữ ảnh người dùng đã tải lên và không lấy trạng thái ảnh chính của chúng. Bản ghi trùng tên hoặc không có trong database được bỏ qua; chạy lại không tạo ảnh trùng. Seed mới dùng cùng danh sách ảnh thật, không chọn ảnh luân phiên. Import kiểm tra tệp ảnh trước khi ghi, chạy trong một transaction và không sửa tọa độ, giá vé hay lịch trình.
